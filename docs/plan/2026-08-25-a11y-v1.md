# 计划：v1.0 无障碍（放映面）

> 状态：已落地
> 日期：2026-08-25
> 关联：VERSION.md v1.0「无障碍（放映面）」已勾。编辑器另开。
> 范围：**放映 / 概览 / 演讲者 / chrome 控件**。编辑器、图工作台另开，不绑本轮。

## 1. 现状

已有：`html lang="zh-CN"`、放映方向键/空格/Home/End/`G`/`F`、`contrastOn`、少量英文 `aria-label`。

缺口：翻页读屏不宣告；进度条无 role；概览不是对话框；菜单只能右键；焦点环弱；无 `prefers-reduced-motion`；sfg/正文对比度未设门禁。

## 2. 本轮

| 项 | 做法 |
|---|---|
| 翻页宣告 | `aria-live="polite"`：第 N 页 · 标题 |
| 进度 | `role="progressbar"` + valuemin/now/max |
| 控件 | 中文 aria-label；`:focus-visible` 环 |
| 概览 | `role="dialog"`，当前页 `aria-current`，打开时焦点落到当前缩略图 |
| 菜单 | `M` 打开（与右键同一菜单）；`role="menu"` |
| 动效 | `prefers-reduced-motion: reduce` 关掉 slide-enter / slide-anim / zoom-anim |
| 对比度 | 纯函数审计 token：正文 ≥4.5、sfg/UI ≥3、on-accent ≥4.5 |

## 3. 非目标

编辑器按钮/表单、X6 画布、Playwright 读屏实测、改种子色算法（只调未过门的 token）。

## 4. Backlog（不急，编辑器轮一起收）

1. **图工作台焦点**：portal + X6 画布，键盘焦点管理单独评估，不要当普通表单做。
2. **概览 focus trap**：`role="dialog"` 已有，Tab 仍可能逃出；与编辑器轮一起做。
3. 编辑器按钮/表单 ARIA；演讲者窗与主窗同步焦点。
